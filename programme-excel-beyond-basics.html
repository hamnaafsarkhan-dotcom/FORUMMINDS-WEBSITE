Excel Beyond the Basics: Modern Tools, Analysis & AI

Overview

Most people who use Excel every day are working with a version of the tool from fifteen years ago. Dynamic arrays, Power Query and the AI features now built into the product have changed what a competent analyst can do in an afternoon — but only if they know the features exist and where they break.

This programme takes delegates past formulas into modern Excel practice: reshaping messy data without manual cleanup, building models that do not collapse when a row is inserted, and using the AI features on real datasets while knowing exactly which outputs need checking.

Everything is taught on realistic business data. Delegates bring problems from their own work where possible, and leave with working files rather than notes.

What you will learn

  • Use dynamic arrays to replace fragile copy-down formulas
  • Clean and reshape messy data with Power Query, repeatably
  • Build models that survive structural changes to the source data
  • Apply LAMBDA and named formulas to remove duplication
  • Use the AI features in Excel and recognise where they mislead
  • Build dashboards that answer a question rather than display everything
  • Audit and stress-test a spreadsheet before anyone relies on it
  • Document a model so a colleague can pick it up

Who should attend

This programme is designed for practitioners in the following roles.

  • Financial analysts
  • Management accountants
  • Planning and reporting teams
  • HR and workforce analysts
  • Operations and commercial analysts

Programme agenda

Day 01

Modern Excel foundations

  • Dynamic arrays: FILTER, SORT, UNIQUE, SEQUENCE and spill behaviour
  • Replacing nested IFs with lookup and logic that reads clearly
  • Power Query: importing, cleaning and reshaping without manual steps
  • Building a refreshable pipeline from a messy monthly export
  • LAMBDA and named formulas for reusable logic
  • Workshop: rebuilding a fragile report as a robust model
Day 02

Analysis, AI and assurance

  • The AI features now in Excel: what they do well
  • Where AI-generated formulas and summaries go wrong, with examples
  • Prompting for analysis: asking questions that produce checkable answers
  • PivotTables and data models for genuine multi-table analysis
  • Dashboard design: one question per view
  • Auditing and stress-testing before anyone relies on the numbers
  • Case exercise: end-to-end build from raw export to reviewed dashboard
